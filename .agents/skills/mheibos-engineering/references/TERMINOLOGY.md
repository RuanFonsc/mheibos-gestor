# Terminologia

- Cliente comercial é o comprador; Cliente Mheibos é aplicação subordinada à Central.
- Pedido é comercial/financeiro; Processo é execução; Etapa é unidade de trabalho.
- Modelo de fluxo é reutilizável; fluxo instanciado preserva uma ocorrência.
- Nomear a dimensão do estado; evitar `status` genérico.
- Evento é fato; evidência o sustenta; auditoria preserva rastreabilidade.
- IA propõe; mecanismos determinísticos autorizam, validam e persistem.
- Arquivo oficial de arte difere de anexo ou referência.

Escrever o termo completo quando houver ambiguidade.
