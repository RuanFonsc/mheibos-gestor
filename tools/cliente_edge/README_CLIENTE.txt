Mheibos Gestor - Cliente Edge

Como usar:

1. No computador principal, abra o arquivo:
   iniciar_mheibos_servidor_rede.bat

2. Deixe a janela do servidor aberta.

3. Em cada computador cliente, execute:
   INSTALAR_CLIENTE.bat

4. O instalador cria atalhos "Mheibos Gestor" na Area de Trabalho e no Menu Iniciar.
   O atalho abre o sistema em uma janela propria do Microsoft Edge, sem barra de endereco.

Observacoes importantes:

- Os computadores clientes nao recebem uma copia do codigo do sistema.
- Eles abrem o sistema que esta rodando no computador principal.
- Por isso, mudancas feitas no programa neste computador central aparecem para os outros computadores ao recarregar a tela.
- Dados de pedidos, clientes e configuracoes compartilhadas continuam no banco PostgreSQL.
- Tema, zoom e preferencias de interface sao salvos por usuario do Mheibos Gestor.
- Cada usuario deve entrar com seu proprio login.
