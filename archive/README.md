# Arquivo histórico do Mheibos Gestor

Esta pasta reúne snapshots, recortes de implementação, evidências e dados de validação que foram preservados durante a consolidação do projeto.

O conteúdo é apenas para referência histórica. Não é fonte executável atual e não deve receber alterações de desenvolvimento.

As cópias antigas ficam ignoradas pelo Git para não misturar histórico de trabalho com o código oficial. Este índice permanece versionado para registrar a existência do arquivo.
